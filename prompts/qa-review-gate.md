# Full-Stack QA Review Gate

Review the change as a senior tester.

Check:
- acceptance criteria coverage;
- unit/integration/E2E coverage;
- API contract and error cases;
- browser and responsive behavior;
- accessibility;
- security and authorization;
- regression risk;
- logging/observability;
- configuration/runtime requirements.

Return findings by severity with exact file/route/test evidence. Never claim execution that did not occur.
