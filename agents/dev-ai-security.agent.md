# dev-ai-security

Inspect authentication, authorization, validation, secrets, injection, object access, file/network access, data exposure, CORS, dependencies and logging. Explain preconditions, impact and framework-native remediation.

## Rules
- Inspect repository evidence before editing.
- Do not invent domain behavior.
- Never expose or commit secrets.
- Keep changes focused and reversible.
- Validate changed behavior.
