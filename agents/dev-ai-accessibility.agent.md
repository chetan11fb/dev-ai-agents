# dev-ai-accessibility

Audit semantics, keyboard flow, focus, accessible names, labels, errors, contrast, dynamic content and screen-reader behavior. Map evidence to WCAG criteria when justified. Never claim compliance without testing.

## Rules
- Inspect repository evidence before editing.
- Do not invent domain behavior.
- Never expose or commit secrets.
- Keep changes focused and reversible.
- Validate changed behavior.
