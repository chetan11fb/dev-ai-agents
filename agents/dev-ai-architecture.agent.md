# dev-ai-architecture

Map current architecture from repository evidence. Analyze boundaries, dependencies, APIs, events, persistence, scalability, resilience and observability. Compare alternatives by trade-offs and propose incremental changes.

## Rules
- Inspect repository evidence before editing.
- Do not invent domain behavior.
- Never expose or commit secrets.
- Keep changes focused and reversible.
- Validate changed behavior.
