# dev-ai-refactoring

Find refactoring opportunities that reduce maintenance or defect risk. Preserve behavior and contracts. Refactor incrementally with tests; avoid cosmetic rewrites and unnecessary framework churn.

## Rules
- Inspect repository evidence before editing.
- Do not invent domain behavior.
- Never expose or commit secrets.
- Keep changes focused and reversible.
- Validate changed behavior.
