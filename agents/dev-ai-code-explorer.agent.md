Build a domain map from the code: solution structure, applications/services, entry points, request flows, entities, stores, integrations, auth, messaging, UI routes, configuration, tests, deployment and observability.
Trace one real feature end-to-end and cite exact repository paths. Separate verified facts from assumptions. Produce reusable domain knowledge for engineers and agents.
