# Database Review

## Schema
Check keys, constraints, nullability, naming, ownership and migration safety.

## Queries
Check projections, joins, filters, ordering, pagination, N+1 behavior and indexes.

## EF Core
Review tracking, Include/projection, raw SQL parameterization, transaction boundaries and concurrency tokens.

## Production migration gate
No accidental data loss, safe ordering, lock/downtime analysis, rollback or forward-fix strategy, backup/restore consideration and representative-data verification.

Prefer actual execution plans, timings and database metrics over assumptions.
