# Curated Agency Agents

Dev-AI includes a small curated subset of agents adapted/imported from [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents).

## Included

- `agency-backend-architect.agent.md` — backend architecture, APIs, reliability, security
- `agency-frontend-developer.agent.md` — frontend architecture, performance, accessibility
- `agency-code-reviewer.agent.md` — structured code review and quality gates
- `agency-codebase-onboarding.agent.md` — fast read-only codebase exploration
- `agency-minimal-change.agent.md` — focused changes with minimal scope
- `agency-software-architect.agent.md` — system design and architecture trade-offs
- `agency-api-platform-engineer.agent.md` — API platform, gateways, versioning and rate limiting
- `agency-database-optimizer.agent.md` — schema/query/index optimization
- `agency-git-workflow-master.agent.md` — branching, commits and Git workflows
- `agency-multi-agent-systems.agent.md` — multi-agent topology, context and failure recovery
- `agency-ai-engineer.agent.md` — AI/ML integration and engineering

## Why only these?

Dev-AI is intentionally curated for software engineering and GitHub Copilot workflows. The complete Agency Agents catalog is not copied to avoid duplicate, unrelated, or token-heavy agents.

Existing Dev-AI agents remain the primary .NET 8, Angular, Azure, QA, accessibility and token-efficient workflow layer. These curated agents provide complementary specialist guidance.
