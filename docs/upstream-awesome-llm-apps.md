# Awesome LLM Apps — Upstream Reference

Source: https://github.com/Shubhamsaboo/awesome-llm-apps
License: Apache-2.0

This directory contains selected upstream reference implementations relevant to developer agents, architecture, coding workflows, GitHub MCP, browser MCP and MCP routing.

Imported source is intentionally kept under `upstream/awesome-llm-apps/`. Native DEV-AI implementations live under `agents/`, `skills/`, `prompts/`, `mcp/`, `plugins/` and `settings/`.

Imported skills retain their original metadata and attribution. Verify upstream changes before syncing future revisions.
